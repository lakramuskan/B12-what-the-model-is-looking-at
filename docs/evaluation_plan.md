# Evaluation Plan


## Baseline


A simple baseline will be established before judging the main model.


## Evaluation


Results will not be reported from only one random run.


Random experiments will use multiple seeds.


## Planned Reporting


For each experiment we will record:


- metric
- average
- best result
- worst result
- standard deviation
- random seed


## Failure Analysis


We will investigate cases where the model's explanation is
misleading or where prediction errors are large.


## Experiment Log


All experiments will be recorded in experiments.csv.

The guidebook requires multiple seeds and reporting the spread rather than presenting one lucky result.
